## 1. 系统简介

InnoCite 是一个学术论文创新点分析与跨学科推荐平台，帮助你：

- **导入论文**：从 arXiv、CSV 文件、PDF 文件或 EndNote 导出文件中批量导入论文
- **提炼创新点**：自动抽取每篇论文的"问题 → 方法 → 效果"三维结构化创新点
- **追踪关键词热度**：通过时序曲线图观察领域内关键词的兴衰变化
- **发现跨学科灵感**：基于论文内容相似度，推荐其他学科的可能迁移到你研究方向的论文
- **生成综合报告**：一键导出包含统计、图表、创新点汇总的 PDF 报告

### 启动系统

```bash
python init_db.py   # 首次使用：初始化数据库
python app.py       # 启动服务
```

浏览器打开 `http://127.0.0.1:5000`。

### 默认账户

| 用户名 | 密码 |
|--------|------|
| `admin` | `admin123` |

> ⚠️ 生产环境请务必修改默认密码。

## 2. 登录系统

打开系统后首先看到登录页面。输入用户名和密码，点击"登录"进入主界面。

- 登录后右上角显示当前用户名
- 点击用户名 → "退出登录"可安全登出
- 未登录状态访问任何功能页面都会自动跳转到登录页
- 关闭浏览器后需重新登录（24 小时内免重新登录）

## 3. 论文导入

系统支持 5 种导入方式，在论文库页面点击"导入论文"按钮，选择对应标签页操作。

### 3.1 arXiv ID 导入

适合导入已知 arXiv ID 的单篇论文。

1. 选择 **arXiv ID** 标签
2. 输入 arXiv ID（如 `2101.00123`）
3. 点击"导入"

系统自动拉取标题、作者、摘要、年份、分类信息，并提取创新点。

### 3.2 关键词搜索导入

适合按主题批量导入论文。

1. 选择 **关键词搜索** 标签
2. 输入搜索关键词（如 `attention mechanism`）
3. 可选：设置年份范围和最大篇数
4. 点击"搜索导入"

系统通过 arXiv API 搜索并批量导入匹配的论文。

### 3.3 CSV 批量导入

适合导入已有的论文数据集。

1. 选择 **CSV 导入** 标签
2. 点击"下载 CSV 模板"获取格式参考
3. 按模板填写论文信息：`title, authors, year, abstract, category`
4. 上传填写好的 CSV 文件
5. 点击"上传导入"

### 3.4 EndNote 导入

适合从知网、万方、PubMed 等数据库导入。

1. 在文献数据库中导出参考文献，选择 **EndNote 格式**（`.enw`）
2. 选择 **EndNote** 标签
3. 上传 `.enw` 文件
4. 点击"上传导入"

### 3.5 PDF 上传

适合导入本地 PDF 论文。

1. 选择 **PDF 上传** 标签
2. 选择 PDF 文件
3. 点击"上传解析"

系统会自动提取标题、作者、摘要、年份等元数据。如果安装了 GROBID（`docker run -d -p 8070:8070 lfoppiano/grobid:0.8.1`），解析精度会显著提升。

## 4. 论文管理

论文库首页展示所有已导入的论文，支持搜索、筛选和操作。

### 搜索与筛选

- **关键词搜索**：在搜索框输入关键词，匹配标题、作者和摘要
- **学科筛选**：下拉选择具体学科分类
- **年份筛选**：在 arXiv 搜索中设置起始/结束年份

### 论文操作

每篇论文右侧有三个按钮：

| 按钮 | 功能 |
|------|------|
| 👁 查看 | 进入论文详情页，查看摘要、创新点和推荐 |
| ✏ 编辑 | 修改创新点内容 |
| 🗑 删除 | 删除论文（同时删除关联的创新点和推荐记录） |

### 数据导出

点击论文库页面的"导出数据"按钮，可选择：

- **导出 CSV**：下载包含创新点信息的表格文件
- **导出 JSON**：下载结构化 JSON 数据

导出的数据会遵循当前的搜索和筛选条件。

## 5. 创新点提炼

### 自动提取

导入论文时，系统自动分析摘要文本，提取三个维度的创新点：

| 维度 | 说明 | 示例 |
|------|------|------|
| **问题** | 论文试图解决的挑战或瓶颈 | "深层神经网络训练困难，现有方法特征选择能力不足" |
| **方法** | 提出的解决方案或技术手段 | "提出 SE-ResNet 架构，引入通道注意力机制" |
| **效果** | 方法达到的性能提升 | "ImageNet top-5 错误率降至 4.1%，准确率提升 2.3%" |

每篇论文会显示一个**置信度百分比**，表示系统对提取结果的自信程度。

### 手动编辑

1. 在论文列表点击 ✏ 编辑按钮
2. 修改"解决的问题"、"采用的方法"、"达到的效果"
3. 右侧实时预览完整陈述
4. 点击"保存创新点"

手动编辑的创新点会被标记为"已确认"（✅），不会被后续的自动提取覆盖。

### 时间线视图

点击论文库页面的"时间线视图"按钮，可以按年份倒序浏览所有创新点的发展脉络。

## 6. 关键词热度趋势

导航栏点击"热度趋势"进入。

### 功能说明

系统使用 TF-IDF 算法从所有论文中提取关键词，计算每个关键词在各年份的出现比例（热度值），绘制时序曲线图。

### 操作步骤

1. 页面左侧显示**热度排名 TOP 20**，点击任意关键词将其加入选择
2. 也可以点击快速选择按钮或在下拉框中搜索关键词
3. 点击"绘制曲线"生成交互式时序图
4. 鼠标悬停曲线可查看具体数据点

### 图表示例解读

- 横轴：年份
- 纵轴：热度值（该年含此关键词的论文占比）
- 上升趋势：该方向研究热度增长
- 下降趋势：该方向可能趋于成熟或过时

> 热度数据会被缓存到数据库。论文数量不变时重复查看几乎瞬间加载。

## 7. 跨学科推荐

导航栏点击"跨学科推荐"进入。

### 功能说明

基于论文内容向量相似度，为你的论文推荐来自**其他学科**的相关论文。例如，计算机视觉研究者可能从自然语言处理领域的论文中找到可迁移的方法。

### 操作步骤

1. 在"选择论文"下拉框中搜索并选择一篇源论文
2. 设置推荐数量（默认 3 条）
3. 点击"获取推荐"

### 结果解读

- **相似度百分比**：目标论文与源论文的内容相似程度
- **学科标签**：目标论文所属学科
- **推荐理由**：解释为什么这篇论文可能对你有启发

> 推荐结果会被缓存到数据库。对同一篇论文重复查询几乎瞬间返回。

## 8. 综合报告与导出

导航栏点击"综合报告"进入。

### 报告页内容

报告页包含四大板块：

1. **统计仪表盘**：论文总数、年份范围、学科数量、平均置信度
2. **关键词趋势 TOP 5**：热度最高的 5 个关键词的时序曲线
3. **学科分布饼图**：各学科论文数量占比
4. **创新点汇总**：按置信度排序的创新点列表
5. **推荐示例**：自动选择一篇代表性论文的跨学科推荐

### PDF 导出

点击"导出 PDF 报告"按钮，系统生成包含以下内容的 PDF 文档：

- 封面与统计概览表
- 学科分布饼图
- 关键词热度曲线图 + 排名表
- 创新点汇总表
- 跨学科推荐示例

> PDF 需要中文字体支持。将 `.ttf` 字体文件放入 `data/` 目录即可正常显示中文。

## 9. 系统管理

### API 文档

导航栏点击"API 文档"可查看完整的 Swagger 交互式 API 文档，支持在线测试所有接口。

### 系统管理操作

以下操作需通过 API 调用（可在 Swagger 文档中执行）：

| 操作 | 说明 |
|------|------|
| 重建 SBERT 嵌入 | `POST /api/rebuild-embeddings` — 清除所有向量并重新计算 |
| 重建推荐缓存 | `POST /api/rebuild-recommendations` — 清除推荐缓存并重新生成 |

## 附录：环境变量配置

系统通过环境变量控制行为，启动前可设置：

```bash
# 环境切换
export APP_ENV=production        # development | testing | production

# 安全
export SECRET_KEY=your-secret    # 生产环境必须设置
export ADMIN_USERNAME=admin      # 管理员用户名
export ADMIN_PASSWORD=strong123  # 管理员密码

# 数据库
export DATABASE_URL=sqlite:///instance/innocite.db

# GROBID（可选）
export GROBID_URL=http://localhost:8070
export GROBID_ENABLED=0          # 设为 0 强制禁用

# 日志
export LOG_LEVEL=DEBUG
```

### 生产环境部署建议

1. 设置强密码的 `SECRET_KEY` 和 `ADMIN_PASSWORD`
2. 使用 `APP_ENV=production` 关闭 Debug 模式和 Swagger UI
3. 考虑将 SQLite 替换为 PostgreSQL（修改 `DATABASE_URL`）
4. 使用 Gunicorn 或 uWSGI 替代 Flask 内置服务器
5. 配置 Nginx 反向代理 + HTTPS
