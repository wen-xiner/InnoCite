使用说明

系统简介

InnoCite 是一个面向研究生和科研人员的学术论文分析平台：

01
提炼创新点
自动抽取"问题-方法-效果"三维结构化创新点，支持手动编辑确认
02
追踪研究热点
关键词热度时序曲线 + 词云，直观展示领域趋势
03
跨学科推荐
基于向量相似度匹配，发现其他学科可迁移的研究方法
04
报告导出
一键生成含图表的 PDF 报告，支持 CSV/JSON 数据导出
功能指南
1 登录与安全

系统启动后需要登录才能使用。默认账户 admin / admin123，生产环境请修改密码。
所有请求受 CSRF 保护，文件上传经过魔数签名校验，防止恶意文件注入。
右上角用户菜单可退出登录。支持暗色模式（点击 ☀ 图标切换）。

2 导入论文

支持 5 种导入方式，点击论文库页面的"导入论文"按钮选择：
• arXiv ID：输入论文 ID（如 2101.00123）直接拉取元数据
• 关键词搜索：通过 arXiv API 批量搜索导入，支持年份筛选，显示导入进度
• CSV 上传：下载模板填写后批量导入，含文件类型校验
• EndNote (.enw)：支持从知网、万方、PubMed 导出的 EndNote 格式文件
• PDF 上传：自动提取元数据。部署 GROBID（Docker 一行命令）可大幅提升解析精度

3 创新点提炼

系统使用规则引擎从摘要中自动抽取"问题→ 方法→ 效果"三维创新点。
论文列表中以彩色环形置信度直观展示提取质量（绿≥70% / 黄≥40% / 红<40%）。
点击 ✏ 编辑按钮可手动修改，已确认（✅）的创新点不会被自动覆盖。

4 关键词热度与词云

系统使用 TF-IDF 从所有论文中提取关键词，计算各年份的出现频率。
热度数据自动缓存，论文数量不变时秒级响应。
在趋势页可以选择多个关键词叠加对比热度曲线。右侧词云按热度缩放关键词，点击即选，直观发现热门方向。

5 跨学科推荐

优先使用 SentenceTransformer（all-MiniLM-L6-v2）生成 384 维语义向量，不可用时自动回退到 TF-IDF。
采用批量矩阵运算一次性计算全部候选相似度，比逐对计算快 100 倍以上。
推荐结果自动缓存，附热力色条直观展示相似度高低，并提供方法迁移建议。

6 报告与导出

综合报告页集成统计仪表盘、学科饼图、热度曲线、创新点汇总和推荐示例。
点击"导出 PDF"生成含图表的离线综合报告（需中文字体文件放入 data/ 目录）。
支持按条件筛选后导出 CSV 或 JSON 格式的完整数据。

7 论文管理

首页表格支持搜索（标题/作者/摘要）和学科筛选。行 hover 左侧弹出彩色指示条。
每篇论文可查看详情、编辑创新点、删除（同时清理关联数据）。
详情页滚动超过摘要区后顶部滑入快速操作悬浮栏，无需滚回顶部。

8 系统管理

通过 Swagger API 文档 可在线测试所有接口。
管理端点支持重建向量嵌入（POST /api/rebuild-embeddings）和重建推荐缓存。
数据库使用 Alembic 管理 schema 迁移：flask db migrate → flask db upgrade。

技术栈
  • 后端框架：Flask 3.x（工厂模式 + 蓝图）
  • 数据库：SQLite + SQLAlchemy ORM + Alembic 迁移
  • 认证安全：Session + CSRF (Flask-WTF) + 文件魔数校验
  • PDF 解析：GROBID（优先）+ pdfplumber（回退）
  • 中文分词：jieba
  • 关键词：TF-IDF (sklearn) + 数据库缓存
  • 日志：RotatingFileHandler（10MB×10 滚动归档）
  • 向量化：SentenceTransformer (all-MiniLM-L6-v2)
  • 推荐：批量矩阵余弦相似度 (sklearn)
  • 可视化：Plotly.js（趋势曲线 + 饼图）
  • PDF 生成：reportlab + plotly.io.write_image
  • 前端：Bootstrap 5 + 暗色模式 + 骨架屏
  • API 文档：Flasgger / Swagger
  • 部署：支持 Docker + 环境变量配置

环境变量
APP_ENV
环境：development / testing / production
ADMIN_USERNAME / ADMIN_PASSWORD
管理员账户（默认 admin / admin123）
GROBID_URL
GROBID 服务地址（默认 localhost:8070）
DATABASE_URL
数据库连接串（默认 SQLite）
注意事项
  • arXiv API 有频率限制，批量搜索会间隔 0.1 秒。
  • 首次启动时 sentence-transformers 会下载约 90MB 模型。
  • PDF 中文报告需将字体文件放入 data/ 目录。
  • SQLite 适用于单机/小团队使用，高并发请换 PostgreSQL。
  • 数据库迁移文件（migrations/versions/）应提交到 Git。
  • 生产环境请设置 SECRET_KEY 并修改默认管理员密码。
